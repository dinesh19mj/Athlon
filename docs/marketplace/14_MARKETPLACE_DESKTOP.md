# 14. MARKETPLACE DESKTOP ARCHITECTURE

> **Module**: Desktop Experience  
> **Status**: IMPLEMENTED & TESTED

## 1. Desktop Experience
- Fixed top navigation header featuring `AppModeSwitcher`, search bar, categories link, wishlist link, "Sell Gear" button, and My Market storefront console.
- Responsive multi-column grids:
  - 4 columns on large screens for product rails.
  - Split 2-column view for product detail pages (left: high-res gallery, right: price telemetry, specs, and seller card).
- Clean integration with existing desktop themes without overflowing or resetting view state.
